Primitive DataTypes: These are of 7 Types
1) String 2) Number 3) Boolean 4) Null 5) undefined 6) Symbol 7) BigInt

Reference (Non primitive):

1) Array: const heros = ["Batman", "IronMan", "Thor", "Captain America"]
 
2) Objects: Key Value Pair
 let obj = {
    name: "Arpit",
    age: 20,
 }
 
3) Functions:
const myfunction = function(){
    console.log("Hello World");
}

Note: The return type of all the non primitive datatypes is object.
console.log(heros) // object
console.log(obj) // object

******** Memory In JavaScript *********
There are Two types of memory in JavaScript
1) Stack (Primitive)   2) Heap (Non Primitive)

Stack: (Call by Value) => We can only change the copy of the variable not the original value.
let myname = "Arpit"

let anothername = myname
anothername = "Abhay"

console.log(myname); // => Arpit
console.log(anothername); // => Abhay

Heap: (Call by Reference) => We can chage the original value because we have access to original value.
let userone = {
    email: "user1@gmail.com",
    upiId: "user@ybl"
}

let userTwo = userone

userTwo.email = "user2@gmai.com"

console.log(userone.email); // user2@gmail.com
console.log(userTwo.email); // user2@gmail.com
